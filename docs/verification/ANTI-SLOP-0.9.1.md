# Design and documentation review: 0.9.1

The session's during mode remains active. No new visual identity, decorative assets or product themes are introduced in this maintenance release. Existing charcoal/warm-white/orange, Plus Jakarta Sans and ENERGY 2 / RHYTHM 2 / MOTION 2 remain unchanged.

The owner's final scope preserves the complete native Admin interface in the release APK and corresponding Android source under GPL. Documentation describes the current server-role checks without claiming that hidden/obfuscated client code prevents copying or grants authorization. Credentials, private signing material and production user data are excluded from public distribution.

Maintained public guides use English. Navigation and source links are checked locally before publishing. Older Indonesian release/test records remain explicitly historical. Release notes state actual test coverage and unverified Android flows rather than promising perfect security or production acceptance.

The release-specific UI test checks guest/forged local-role navigation under the actual release build flag while retaining the native tools. SQL tests cover server authorization separately. Source audits and GitHub protection settings have their own evidence. Component/JVM tests are not described as physical Android execution.
